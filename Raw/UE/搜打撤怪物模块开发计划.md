## 阶段 P1：地基（1-2 周）

**目标**：造出一个**能站在地图上、你能打死它、死了会掉个包**的"最简怪物"。

### P1.1 工程初始化
- [ ] 开新项目：UE5 空项目 或 ThirdPerson 模板
- [ ] 启用插件：`GameplayAbilities` / `AIModule`
- [ ] 创建游戏模块：`Source/YourGame`
- [ ] `Build.cs` 加依赖：`AIModule, GameplayTasks, NavigationSystem`
- [ ] 设置 PIE 多人测试：Number of Players = 2，Dedicated Server = ON

### P1.2 最简怪物 Character
- [ ] 创建 `AMonsterCharacter : ACharacter`
- [ ] 设置 `bReplicates = true`
- [ ] 加 SkeletalMesh 组件（先用 UE 自带 Mannequin）
- [ ] 加 Health 成员（`UPROPERTY(ReplicatedUsing=OnRep_Health) float CurrentHealth`）
- [ ] 实现 `GetLifetimeReplicatedProps` 注册同步
- [ ] 实现 `TakeDamage` 函数（UE 自带 virtual）
- [ ] Health 归零时 `Die()` → 播死亡动画 → `Destroy()`
- [ ] 关卡里手动摆一个测试

### P1.3 玩家能打
- [ ] 玩家角色用模板自带的即可（或 Lyra 里的）
- [ ] 玩家武器做最简射线 LineTrace
- [ ] 命中 `AMonsterCharacter` 时 `Server_TakeDamage(Amount)`

### P1.4 最简掉落
- [ ] 创建 `AMonsterLootBox : AActor`
- [ ] 怪物 `Die()` 时 `SpawnActor<AMonsterLootBox>`
- [ ] 玩家走近按 E → 屏幕 `PrintString("捡到了 X")`（UI 暂不做）

### P1.5 多人验证
- [ ] PIE 开 2 个客户端
- [ ] 客户端 A 打怪物 → 客户端 B 看到 Health 下降
- [ ] 怪物死亡 → 两边同时消失 → 两边都看到 LootBox
- [ ] 任一客户端交互 LootBox 都能捡

**P1 完成标志**：多人环境下可以稳定打死一只怪 + 捡到它的掉落。

## 阶段 P2：让怪物会动（2-3 周）

**目标**：怪物能**看到玩家 → 朝玩家移动 → 在一定距离停下**。

### P2.1 NavMesh（寻路网格）
- [ ] 关卡放 `NavMeshBoundsVolume`，覆盖可走区域
- [ ] 按 P 键确认绿色 NavMesh 生成正常
- [ ] 调整 `RecastNavMesh` 参数：`Cell Size`、`Agent Radius`、`Agent Step Height`
- [ ] 有楼梯/斜坡的地方单独验证

### P2.2 AIController 骨架
- [ ] 创建 `AMonsterAIController : AAIController`
- [ ] `AMonsterCharacter` 的 `AIControllerClass` 指定上面这个
- [ ] 创建 `BB_Monster`（Blackboard Data Asset）
  - [ ] Key: `TargetActor` (Object, Base = Actor)
  - [ ] Key: `TargetLocation` (Vector)
  - [ ] Key: `HomeLocation` (Vector)
  - [ ] Key: `LastDamageDirection` (Vector)
- [ ] 创建 `BT_Monster`（BehaviorTree）使用上面 BB
- [ ] `AIController::OnPossess` 里 `RunBehaviorTree(BT_Monster)`
- [ ] `OnPossess` 里把 Character 初始位置写到 `HomeLocation`

### P2.3 巡逻行为
- [ ] 自定义 `UBTTask_FindRandomLocation`
  - [ ] 在 `HomeLocation` 周围 500-1000m 随机找 NavMesh 点
  - [ ] 写到 `TargetLocation`
- [ ] 行为树搭建巡逻分支：
  - [ ] Sequence：`FindRandomLocation` → 内置 `MoveTo TargetLocation` → 内置 `Wait 2-5s`
- [ ] 验证：怪物在 Home 点周围走动，不卡墙

### P2.4 感知系统
- [ ] `AMonsterAIController` 加 `UAIPerceptionComponent`
- [ ] 配 `AISenseConfig_Sight`（视野 3000cm，角度 90°）
- [ ] 绑定 `OnTargetPerceptionUpdated`
  - [ ] 看到玩家：`Blackboard->SetValueAsObject("TargetActor", Player)`
  - [ ] 失去视野 5 秒：清空 `TargetActor`
- [ ] 验证：进入视野触发，离开视野 5s 后清空

### P2.5 追击行为
- [ ] 行为树加战斗分支（优先级高于巡逻）
  - [ ] Condition：`TargetActor != null`
  - [ ] `MoveTo TargetActor`（接受半径 500cm，先只追不打）
- [ ] 验证：看到玩家 → 追 → 500cm 内停 → 玩家跑远失去视野 → 回巡逻

**P2 完成标志**：怪物有巡逻 / 警戒 / 追击三种状态，切换自然。

## 阶段 P3：让怪物会打（2-3 周）

**目标**：怪物**在追到目标后朝玩家开枪，打掉玩家血**。

### P3.1 给怪物装武器
- [ ] 创建 `AMonsterWeapon : AActor`（或组件）
- [ ] 数据字段：`Damage` / `FireRate` / `Range` / `MaxAmmo` / `CurrentAmmo` / `SpreadDegree`
- [ ] 函数：`Fire(FVector AimLocation)` 做 LineTrace
- [ ] 命中时 `DrawDebugLine` 可视化
- [ ] `AMonsterCharacter::BeginPlay` 里 `SpawnAttach` 默认武器到手部 Socket

### P3.2 ShootTarget 行为
- [ ] 自定义 `UBTTask_ShootTarget`
- [ ] `TickTask` 逻辑：
  - [ ] 读 `TargetActor`
  - [ ] 视线检查（LineTrace 看是否被墙挡）
  - [ ] 距离在武器 Range 内
  - [ ] FireRate 冷却判定
  - [ ] 满足条件 → `Weapon->Fire(TargetLocation)`
- [ ] 行为树战斗分支更新：
  - [ ] `MoveTo TargetActor`（距离 <= 2000cm 停）
  - [ ] `ShootTarget`（持续）

### P3.3 命中率调控
- [ ] `AMonsterCharacter` 加 `SkillLevel`（0.0-1.0）
- [ ] `ShootTarget` 计算 AimPoint：
  - [ ] 基础 = `TargetActor->GetActorLocation()`
  - [ ] 散布：根据 `SkillLevel` 加随机圆锥偏移
  - [ ] 反应延迟：刚发现目标 0.3-1.5s 内不开火
- [ ] 配置不同怪物的 SkillLevel：
  - [ ] Scav: 0.3
  - [ ] Raider: 0.7
  - [ ] Boss: 0.9

### P3.4 怪物受击反馈
- [ ] `TakeDamage` 里播受击动画 Montage
- [ ] 被打时记录 `LastDamageDirection` 到 Blackboard
- [ ] 行为树加"受击反应"分支（优先级高于战斗）
  - [ ] 转向伤害方向
  - [ ] 进入警戒状态 3 秒
- [ ] 死亡时：Ragdoll + 播死亡动画（不立即消失）

**P3 完成标志**：可以和一只会开枪的怪物对战，手感初步成立。

## 阶段 P4：GAS 战斗系统（3-4 周，难度跃升）

**目标**：把伤害 / HP / 属性全部重写为 GAS 驱动，**玩家 / 怪物共用战斗管线**。

⚠️ **注意**：这一步难度跳跃最大，新手可能要花 2 周边学边写。不要跳过。

### P4.1 GAS 基础接入
- [ ] 项目启用 `GameplayAbilities` 插件（P0 已做，确认一下）
- [ ] `Build.cs` 加 `GameplayAbilities, GameplayTags, GameplayTasks`
- [ ] 创建 `UCombatAttributeSet : UAttributeSet`
  - [ ] `MaxHealth` / `Health` / `MaxShield` / `Shield`
  - [ ] `Armor` / `MoveSpeed` / `AttackPower`
  - [ ] 用 `ATTRIBUTE_ACCESSORS` 宏生成访问器
- [ ] `AMonsterCharacter` 加 `UAbilitySystemComponent`
- [ ] 实现 `IAbilitySystemInterface::GetAbilitySystemComponent`
- [ ] `BeginPlay` 初始化 Attribute 值

### P4.2 玩家侧也接 GAS
- [ ] 玩家 Character 也加 ASC + AttributeSet（共用 `UCombatAttributeSet`）
- [ ] 这样玩家 / 怪物是对称的

### P4.3 伤害走 GameplayEffect
- [ ] 创建 `GE_Damage`（Instant 类型）
  - [ ] 修改 `Health`，值用 SetByCaller
  - [ ] 定义 Damage Tag（`Data.Damage`）
- [ ] 武器 `Fire` 命中后：
  - [ ] `MakeOutgoingSpec(GE_Damage)`
  - [ ] `Spec.SetByCaller(Tag, DamageAmount)`
  - [ ] `TargetASC->ApplyGameplayEffectSpecToSelf`
- [ ] `UCombatAttributeSet::PostGameplayEffectExecute`：
  - [ ] 检测 `Health <= 0` → 调 `Die()`
- [ ] 删除原来的 Health 成员 + TakeDamage（全部走 GAS）

### P4.4 部位伤害
- [ ] `AMonsterCharacter` 加 `TMap<FName, float> BodyPartHP`
  - [ ] `head` / `thorax` / `stomach` / `arm_l` / `arm_r` / `leg_l` / `leg_r`
- [ ] 武器 `Fire` 命中时读 `HitResult.BoneName`
- [ ] 映射 BoneName → BodyPart
- [ ] 部位倍率：头 3x / 胸 1x / 腹 0.8x / 四肢 0.5x
- [ ] 头或胸 HP = 0 → 必死
- [ ] 腿 HP = 0 → `HasLegFracture = true`，移动速度减半

### P4.5 装甲 + 弹药
- [ ] 定义 `FArmorData`：`Class (1-6)` / `Durability` / `Coverage`
- [ ] 定义 `FAmmoData`：`Damage` / `ArmorPenetration` / `ArmorDamage`
- [ ] 命中结算：
  - [ ] 装甲覆盖 + 未破？
  - [ ] 穿透概率 = `CalcPen(Pen, ArmorClass)`
  - [ ] 穿：伤害打折（0.85x）+ 装甲扣耐久（0.5x）
  - [ ] 未穿：钝伤（0.15x）+ 装甲扣耐久（1.0x）
- [ ] 不同 AI 穿不同装甲：Scav 无甲 / Raider 3-4 级 / Boss 5-6 级

**P4 完成标志**：玩家和 AI 完全对称战斗，调武器/弹药/装甲表能直接改变战斗体验。

## 阶段 P5：AI 战术丰富（2-3 周）

**目标**：让 AI 不只会站着打，**会找掩体、会换弹、会撤退、会配合**。

### P5.1 掩体系统
- [ ] 关卡摆放 `ACoverPoint` Actor（手动布点）
- [ ] `UCoverManagerComponent`（GameInstanceSubsystem）管理全局掩体
- [ ] 查询接口：`FindCoverFromDirection(Pos, EnemyDirection, MaxDistance)`
- [ ] 自定义 `UBTTask_MoveToCover`
- [ ] 行为树受击分支：受击 → 找掩体 → 蹲下 → 过 3-5s 探头

### P5.2 换弹
- [ ] `AMonsterWeapon` 的 `CurrentAmmo` 消耗
- [ ] Blackboard Key：`NeedReload`
- [ ] Service 节点监控 Ammo < 20% → `NeedReload = true`
- [ ] 换弹分支：找掩体 → 播换弹动画 → `CurrentAmmo = MaxAmmo`
- [ ] Ammo = 0 时强制换弹（中途不开火）

### P5.3 扔手雷
- [ ] 创建 `AGrenadeProjectile : AActor`（走物理弧线）
- [ ] 命中/超时爆炸 → 造成 `GE_Damage`
- [ ] 自定义 `UBTTask_ThrowGrenade`
- [ ] 触发条件：5 秒没打到玩家 / 玩家固定掩体后 / 随机 20% 概率
- [ ] 每个 AI 冷却 20-30s 一个

### P5.4 Squad 协调（初级）
- [ ] `USquadComponent`（挂在关卡一个 Manager Actor 上）
- [ ] 2-3 个 AI 组一队
- [ ] 共享信息：
  - [ ] 一个 AI 发现目标 → 所有队员 Blackboard 写入 `TargetActor`
  - [ ] 一个被击杀 → 全队进入警戒
- [ ] 简单分工：`Leader` / `Member`（先不做复杂包抄）

### P5.5 Boss 雏形（可选进阶）
- [ ] `ABossMonster : AMonsterCharacter`
- [ ] `Phase` 枚举（Phase1 / Phase2 / Phase3）
- [ ] HP < 50% 切 Phase2（攻速提升）
- [ ] HP < 20% 切 Phase3（召唤 2 个 Raider 护卫）
- [ ] Boss 专属 `BT_Boss`
- [ ] 专属死亡演出（慢动作 + 广播全图）

**P5 完成标志**：AI 有明显战术层次，玩家需要思考而不是站桩对枪。

## 阶段 P6：刷怪与战局集成（1-2 周）

**目标**：怪物能**按规则刷到地图里**，形成完整战局生态。

### P6.1 Spawner（刷怪点）
- [ ] 创建 `AMonsterSpawner : AActor`
  - [ ] `MonsterClass` / `SpawnRadius` / `MaxAlive` / `RespawnDelay`
- [ ] Tick 检查存活数量，不够就找 NavMesh 点刷
- [ ] 关卡摆 10-20 个 Spawner，测试密度
- [ ] Spawner 可视化 Gizmo（编辑器里能看到刷点和半径）

### P6.2 掉落表
- [ ] 创建 `DT_MonsterLoot`（DataTable，继承 `FMonsterLootRow`）
  - [ ] `MonsterClass` / `ItemID` / `MinCount` / `MaxCount` / `Probability`
- [ ] 怪物 `Die()` 时读表生成物品
- [ ] 物品放入 LootBox（P1 做过）
- [ ] 配置：
  - [ ] Scav：子弹 + 破烂
  - [ ] Raider：中端武器 + 医疗
  - [ ] Boss：独占稀有物

### P6.3 AI Director（可选进阶）
- [ ] `UAIDirectorSubsystem : UWorldSubsystem`
- [ ] 管理全局 AI 总数上限
- [ ] 动态密度：战局时间 → 刷新速率
  - [ ] 0-2 min：30% 密度
  - [ ] 2-10 min：60% 密度
  - [ ] 10-20 min：60% 维持
  - [ ] 20+ min：剩余 30%
- [ ] 全局 Squad 分配

### P6.4 任务系统接入（可选）
- [ ] 击杀事件广播：`OnMonsterKilled.Broadcast(MonsterClass, KillerId)`
- [ ] 任务系统（如果项目有）订阅这个事件更新进度

**P6 完成标志**：一局游戏里有完整的怪物生态，不是手摆几只沙包。

## 附录 B：常见坑点预警

1. **GAS 学习曲线陡峭**：P4 预留足够时间，不要赶
2. **Behavior Tree 调试困难**：第一次写 BT 会有各种"AI 为啥不动"，GameplayDebugger 是救命工具
3. **Replication 的坑**：Server-only 的代码不要写在 Client 跑的地方（`HasAuthority()` 检查到处加）
4. **NavMesh 重建慢**：大地图改 Nav 参数会卡几分钟
5. **Ragdoll 物理炸开**：死亡瞬间速度给大容易飞天，需要调整物理参数
6. **Perception 重复触发**：OnTargetPerceptionUpdated 会多次触发，要判断 `Stimulus.WasSuccessfullySensed()`
7. **AIController 生命周期**：Pawn 销毁时 Controller 默认也销毁，注意引用别悬空
