
游戏玩法往往不是凭空产生的，而是在已有品类基础上，通过核心规则的组合、替换和强化不断演化而来。团队对抗可以发展出强调英雄技能、经济成长和推塔目标的 MOBA，也可以发展出强调枪械操作、回合攻防和战术配合的 CS / CF 类射击；当射击玩法进一步加入大规模生存、资源搜集和安全区收缩机制，就形成了以《绝地求生》为代表的大逃杀；而当玩家从“裸装进场”变为“携带局外资产进场”，并且只有成功撤离才能真正带回收益时，就演化出以《逃离塔科夫》为代表的搜打撤玩法。

那么，在这种高度强调风险、物资和撤离的硬核搜打撤框架中，加入 SLG 式基地建设、兵工厂生产、蓝图研发、角色养成和联盟前线推进是否可行？本方案尝试讨论一种更适合二次元用户的“轻量搜打撤 + SLG 化局外经营”模式：它不复刻传统搜打撤的“死亡全掉”，也不照搬传统 SLG 的大地图攻城掠地，而是将“局内撤离的紧张感”和“局外长期建设目标”结合起来，探索二次元用户与 SLG 用户之间的融合可能。

## 1. 项目方向概述

本方案讨论的是一种结合“轻量搜打撤”与“SLG 基建经营”的二次元游戏模式：玩家派遣角色小队进入战区搜集物资、完成战斗并成功撤离，将带回资源投入基地建设、兵工厂生产、蓝图研发、角色养成和联盟前线推进，再携带自制装备挑战更高风险区域。方案重点不是复刻传统硬核搜打撤的“死亡全掉”，也不是照搬传统 SLG 的大地图掠夺，而是通过“局内风险决策 + 局外长期养成 + 赛季联盟目标”形成更适合二次元用户的持续循环。

推荐定位可以概括为：

> **二次元小队撤离 + 基地经营 + 军工制造 + 联盟前线赛季。**

这不是简单复制《逃离塔科夫》的硬核搜打撤，也不是传统 SLG 的大地图攻城掠地，而是尝试把“局内撤离紧张感”和“局外长期建设目标”结合起来。

## 2. 为什么要在搜打撤中掺入 SLG 模式

我们并不是为了“像 SLG 所以加 SLG”，而是因为二次元搜打撤本身存在几个核心矛盾：

1. 传统搜打撤后期容易出现物资膨胀；
2. 硬核撤离惩罚与二次元用户的养成偏好存在冲突；
3. 单纯搜打撤长期目标有限，需要更强的局外成长承接；
4. 二次元产品需要角色、小队、基地、联盟和赛季荣誉形成长期情感连接。

SLG 基建、兵工厂、联盟前线和赛季订单可以作为解决这些矛盾的系统承接层，让物资有长期消耗，让角色和基地有长期成长，让赛季有组织目标和最终荣誉。

### 2.1 原因一：缓解传统搜打撤后期物资膨胀

传统搜打撤的基础循环是：

```text
进局 → 搜物资 → 打架 → 撤离 → 存仓库 / 卖钱 / 买装备 → 再进局
```

前期玩家什么都缺，物资价值很高。但随着时间推移，高手玩家和高活跃玩家会逐渐形成稳定正收益：

```text
进局收益 > 出局消耗
```

这会导致仓库资源和装备持续膨胀，风险感下降，搜集欲下降。传统硬核搜打撤通常通过赛季 wipe 或清空仓库来解决经济膨胀，但这种方式对二次元用户和轻度用户并不友好。

引入 SLG 后，物资不只用于买装备，而是进入更多消耗口：

- 基地建设；
- 建筑升级；
- 兵工厂生产；
- 科技研发；
- 军工订单；
- 联盟前线建设；
- 赛季资源投放；
- 武器维护与改造。

这样能用更温和的方式吸收物资，而不是粗暴清空玩家资产。

### 2.2 原因二：二次元用户更偏养成，不适合纯硬核搜打撤

二次元玩家通常更重视：

- 角色收集；
- 角色养成；
- 小队搭配；
- 羁绊关系；
- 外观展示；
- 剧情参与；
- 长期资产积累。

而传统硬核搜打撤强调：

- 高死亡惩罚；
- 装备丢失；
- 强 PVP 对抗；
- 信息不透明；
- 单局高压力；
- 失败损失严重。

如果直接做硬核搜打撤，会出现一个问题：玩家喜欢某个角色、某套装备、某个小队，但系统不断让他承担高额损失，导致玩家不敢用、用不起、舍不得用。

因此更适合做：

> **轻量搜打撤 + 中重度局外养成。**

局内保留紧张感，失败损失可控；局外通过基地、兵工厂、角色、小队、联盟和赛季目标承接长期成长。

### 2.3 原因三：SLG 能提供更强的长期目标

传统搜打撤的长期目标主要是做任务、攒装备、打排位、攒钱、解锁商人等。一旦任务做完、仓库满了、装备稳定，目标感会下降。

SLG 可以提供更多长期目标：

- 基地建设；
- 产线扩展；
- 科技研发；
- 蓝图收集；
- 联盟前线建设；
- 赛季订单；
- 战区推进；
- 联盟排名；
- 个人贡献；
- 服务器战役史。

这些目标能够支撑更长周期的活跃。

### 2.4 原因四：SLG 能让物资价值更立体

传统搜打撤里，很多物资最后会被抽象成“卖多少钱”。而 SLG 可以让物资产生多种用途：

| 物资类型 | 可能用途 |
|---|---|
| 钢材 | 建筑升级、枪械制造 |
| 芯片 | 电子装备、无人机、雷达 |
| 医疗材料 | 医疗站升级、药品生产 |
| 情报数据 | 解锁战区、撤离点、Boss 信息 |
| 燃料 | 出战消耗、基地运转 |
| 蓝图 | 解锁武器、防具、特殊装备 |
| 稀有核心 | 赛季科技、联盟前线建设 |

这样玩家搜东西时不只是看价格，而是会思考它能否帮助自己开建筑、造武器、完成订单、推进联盟目标。

### 2.5 原因五：SLG 能承接联盟、赛季和分享欲

传统搜打撤通常偏个人或小队，但长期运营需要组织归属和赛季记忆。SLG 可以通过联盟订单、前线建设、联盟战报、个人战报、服务器战役史等系统，强化玩家的参与感、归属感和分享欲。

## 3. 产品定位与核心循环

推荐产品定位为：

> **二次元战术撤离 RPG / SLG。**

核心循环如下：

```text
派出二次元小队进入危险战区
  ↓
搜索军工物资 / 蓝图 / 情报 / 特殊资源
  ↓
与敌人、怪物、其他势力或玩家对抗
  ↓
成功撤离后物资进入基地仓库
  ↓
升级基地、建设兵工厂、研发科技
  ↓
生产武器、防具、弹药和战术装备
  ↓
强化角色和小队，再进入更高风险区域
```

这个循环中，局内提供紧张感和资源获取压力，局外提供长期目标和养成反馈。

## 4. 为什么推荐轻量搜打撤，而不是硬核搜打撤

二次元风格下，不建议采用纯硬核搜打撤。推荐做轻量搜打撤，保留紧张感，但降低强惩罚。

| 机制 | 硬核搜打撤 | 二次元推荐版本 |
|---|---|---|
| 死亡损失 | 装备大概率全掉 | 只掉本局战利品，装备耐久损耗 |
| 单局时长 | 25-45 分钟 | 8-15 分钟 |
| 信息透明度 | 很低 | 地图目标、风险等级更清晰 |
| 撤离难度 | 高压、堵点严重 | 有风险，但可控 |
| 装备来源 | 高度稀缺 | 可通过基地稳定生产 |
| 角色死亡 | 高惩罚 | 不永久损失，只进入疲劳 / 治疗状态 |
| PVP 压力 | 很强 | PVE 为主，PVP 可选或分层 |

核心原则是：

> **战斗体验可以紧张，但资产损失必须温和；策略深度放在小队搭配、基地建设、兵工生产和赛季目标上，而不是放在死亡全掉的硬核惩罚上。**

## 5. SLG 基建与兵工厂设计

### 5.1 基地建筑方向

基地可以包含：

| 建筑 | 功能 |
|---|---|
| 指挥中心 | 决定基地等级、解锁建筑上限 |
| 仓库 | 存储物资，决定容量 |
| 兵工厂 | 制造武器、防具、弹药 |
| 科研所 | 解锁蓝图、配件、特殊科技 |
| 医疗站 | 降低受伤惩罚，生产药品 |
| 情报中心 | 提供资源预测、撤离点情报 |
| 训练场 | 提升角色 / 小队能力 |
| 贸易站 | 资源兑换、订单、市场功能 |

### 5.2 兵工厂作为核心差异点

兵工厂可以拆成三层：

1. **蓝图解锁**
   - 通过撤离、高危战区、赛季任务获得蓝图；
   - 蓝图决定可制造装备；
   - 分为常规蓝图、稀有蓝图、赛季蓝图。

2. **材料制造**
   - 武器通过撤离材料合成；
   - 高级装备需要稀有材料和高等级产线；
   - 玩家可以选择量产基础装备，或集中资源制造高级装备。

3. **装备定制**
   - 枪管、弹匣、瞄具、芯片、涂装等模块化配置；
   - 配件影响战斗属性和角色适配；
   - 形成“我的基地生产我的装备”的归属感。

### 5.3 基地不应单线毕业，而应横向扩展

如果基地只是单线升级，迟早毕业。因此更适合做多产线扩展：

| 产线 | 功能 |
|---|---|
| 枪械产线 | 制造主武器 |
| 防具产线 | 制造护甲、防弹插板 |
| 弹药产线 | 制造不同弹种 |
| 电子产线 | 制造芯片、雷达、无人机 |
| 医疗产线 | 制造药品、复苏装置 |
| 载具产线 | 制造载具模块 |
| 特种装备线 | 制造撤离信标、干扰器、探测器 |

每个赛季可以开放新产线或新分支，避免基地毕业后失去目标。

## 6. 风险、损失与 PVP 收益设计

不建议采用“死亡全掉”的硬核规则，但也不能让 PVP 胜利缺乏收益。更推荐采用：

> **长期资产保护 + 本局收益可争夺 + 高危赌注自愿掉落 + 击败奖励补偿。**

这样既能保护二次元玩家的角色和长期养成资产，又能保证攻击方在击败其他玩家时有明确收益和爽感。

### 6.1 分层损失机制

| 层级 | 内容 | 战败后处理建议 |
|---|---|---|
| 长期资产层 | 角色、角色等级、好感、基地资源、核心蓝图、已绑定主武器 | 不掉落，不被其他玩家掠夺 |
| 出战消耗层 | 弹药、药品、装备耐久、无人机耐久、战术装置电量 | 正常消耗或损耗，不返还 |
| 本局收益层 | 本局搜到的物资、空投、Boss 材料、战区货币、未放入安全箱的任务样本 | 可掉落，可被击败者夺取 |
| 高危赌注层 | 高价值运输箱、红区门票、军工样本容器、高倍率资源背包、未绑定高级装备 | 玩家自愿携带，失败后可掉落，成功撤离收益更高 |

这种设计的核心是：

- 不掠夺玩家长期资产，避免强挫败；
- 允许争夺本局收益，保留搜打撤的紧张感；
- 通过高危赌注提供硬核玩家需要的高风险高收益；
- 通过击败奖励保证攻击方有正反馈。

### 6.2 可掠夺背包，而不是全身掉落

可以将玩家携带内容拆成两个区域：

```text
战术装备栏：角色装备，不掉落，只损耗耐久
战利品背包：本局获得物资，可被抢夺
```

击败玩家后，主要掠夺的是对方的“战利品背包”，而不是对方长期养成出来的角色装备。

这样 PVP 爽点仍然存在：

> 我打赢了他，他刚搜到的高价值物资归我了。

但不会变成：

> 我把他养了半个月的武器直接抢走了。

### 6.3 击败奖励包

如果只依赖对方背包，攻击方收益可能不稳定。因此可以额外设计系统生成的击败奖励。

击败玩家后可获得：

- 敌方铭牌；
- 战区积分；
- 悬赏凭证；
- PVP 商店货币；
- 联盟战区贡献；
- 赛季击败记录；
- 特殊称号进度。

这些奖励不是从被击败玩家长期资产中扣除，而是系统根据击败行为生成。这样可以保证攻击方有收益，同时避免被击败方损失过重。

### 6.4 高危区可以提高掉落强度

不同战区可以使用不同掉落规则：

| 战区 | 掉落规则 |
|---|---|
| 日常区 | 只掉本局部分物资，装备只损耗耐久 |
| 高危区 | 掉落本局大部分或全部物资，部分临时装备可掉落 |
| 红区 | 掉落全部本局物资，并允许高危赌注物掉落 |
| 赛季决战区 | 玩家自愿接受更高风险规则，收益倍率也更高 |

这样轻度玩家不会被强惩罚，核心玩家也能主动选择更刺激的玩法。

### 6.5 战术保管舱 / 安全箱

可以设计“战术保管舱 / 安全箱”来降低挫败，同时制造策略选择：

- 容量有限；
- 放入其中的物资失败也能带回；
- 可通过基地升级扩大容量；
- 高价值物资占用更多格子；
- 部分高危任务物品不可放入安全箱；
- 安全箱强化的是保底，不应完全消除风险。

玩家需要在局内不断做判断：

```text
我把什么放安全箱？
我继续搜还是撤？
我是否携带高危赌注物？
我是否为了更高收益进入红区？
```

### 6.6 推荐最终规则

推荐总结为：

```text
玩家被击败后：
1. 已绑定角色装备不掉落，但损失耐久；
2. 已消耗弹药、药品不返还；
3. 本局搜到且未放入安全箱的物资掉落；
4. 玩家主动携带的高风险赌注物会掉落；
5. 击败者获得敌方铭牌、战区积分、悬赏凭证、联盟贡献等系统奖励；
6. 红区 / 赛季决战区可开放更高掉落规则。
```

这套规则兼顾：

- 被击败方不崩溃；
- 攻击方有收益；
- 高危区有刺激；
- 二次元用户能接受；
- 核心玩家也有追求。

## 7. 资源消耗与活跃驱动

由于本模式不像传统 SLG 那样有基地被攻击、兵损和建筑损坏，因此必须建立主动消耗系统。

### 7.1 出战基础消耗

每局都应存在基础投入：

- 弹药；
- 药品；
- 装备耐久；
- 情报票据；
- 后勤补给；
- 撤离费用。

高手可以正收益，但不能零成本刷资源。

### 7.2 持续生产消耗

物资应持续用于生产：

- 武器；
- 防具；
- 弹药；
- 药品；
- 无人机；
- 探测器；
- 干扰器；
- 维修包；
- 撤离信标。

形成：

```text
搜资源 → 生产装备/补给 → 出战消耗 → 再搜资源
```

### 7.3 订单消耗

通过军工订单、前线订单、阵营委托持续向玩家要资源。

订单类型包括：

| 订单类型 | 作用 |
|---|---|
| 日常订单 | 稳定日活 |
| 周常订单 | 提供中期目标 |
| 赛季订单 | 提供长期目标 |
| 联盟订单 | 强化社交协作 |
| 限时战区订单 | 制造短期热点 |

### 7.4 前线建设消耗

通过联盟或全服前线建设消耗大量资源：

```text
全服 / 联盟共同建设前线据点
  ↓
提交资源、装备、情报
  ↓
解锁新地图、新撤离点、新 Boss、新商店
  ↓
获得个人贡献和联盟排名
```

这能替代传统 SLG 的“打别人基地”消耗。

### 7.5 武器生命周期

武器不应一次制造永久毕业。可以设计：

- 耐久损耗；
- 维修成本递增；
- 改造消耗；
- 退役回收；
- 赛季适配模块。

### 7.6 角色状态消耗

二次元适合角色状态，而不是硬惩罚：

- 疲劳；
- 轻伤；
- 重伤；
- 心情；
- 装备适配度；
- 小队协同值；
- 后勤补给状态。

---

## 8. 战区与 PVP 分层

推荐将战区分为三层：

### 8.1 日常探索区

- PVE 为主；
- 撤离压力低；
- 掉落基础材料；
- 适合轻度玩家日常刷资源。

### 8.2 高危争夺区

- PVE + 弱 PVP 或异步竞争；
- 掉落更高价值资源；
- 撤离点更少；
- 适合中度玩家。

### 8.3 红区 / 赛季战区

- 高风险高收益；
- 可开放真人 PVP；
- 掉落赛季蓝图、稀有材料、限定资源；
- 适合核心玩家和赛季目标追逐。

PVP 不应覆盖所有成长路径。主线资源应通过 PVE 可获得，PVP 是效率更高或荣誉更高的选择，而不是唯一选择。

---

## 9. 赛季重置设计

二次元产品不适合完全清空玩家资产。推荐采用软重置：

| 内容 | 是否重置 |
|---|---|
| 角色等级 / 好感 / 突破 | 不重置 |
| 基地核心建筑 | 不重置 |
| 常规蓝图 | 不重置 |
| 普通材料 | 部分压缩或转化 |
| 赛季材料 | 重置或过期 |
| 赛季兵工科技 | 重置 |
| 赛季地图进度 | 重置 |
| 排名 / 战区占领 | 重置 |

核心原则：

> **不重置情感资产和长期资产，只重置赛季经济和赛季目标。**

每个赛季通过新战区、新资源、新蓝图、新敌人、新科技线刷新目标，而不是简单清空玩家库存。

---

## 10. 对比传统 SLG 的赛季处理启发

传统 SLG，尤其是《万国觉醒》这类产品，并不是通过每个赛季清空玩家账号资产来重启循环，而是采用：

> **长期资产保留 + 临时赛季战场 + 战争资源消耗 + 联盟目标竞争 + 赛季荣誉结算。**

这对本方案有重要参考价值。

### 10.1 万国觉醒的赛季切换方式

《万国觉醒》的核心赛季玩法是 KVK / 失落之地。它的结构大致是：

```text
主世界长期保留
  ↓
赛季期开启临时大地图：失落之地
  ↓
多个王国进入同一战场
  ↓
联盟 / 王国争夺关卡、圣地、建筑、中心目标
  ↓
赛季结束
  ↓
失落之地关闭，玩家回到原王国
```

也就是说，它不是清空玩家主城、武将、科技和资源，而是通过临时赛季战场承载赛季竞争。

### 10.2 万国觉醒保留什么、重置什么

| 类型 | 处理方式 |
|---|---|
| 主城等级、建筑、常规科技 | 长期保留 |
| 武将 / 统帅与养成 | 长期保留 |
| 常规资源、道具、加速、外观 | 通常保留 |
| 兵力 | 已有兵力保留，但战争中的伤兵 / 死兵需要玩家承担 |
| 失落之地地图 | 赛季结束关闭，下赛季重新开启 |
| 关卡、圣地、中央建筑归属 | 随赛季重置 |
| 赛季任务、赛季排名、赛季活动 | 赛季结算后重置 |
| 部分赛季科技 / 临时强化 | 赛季结束失效 |

其本质是：

> **不重置玩家长期养成，重置赛季战场状态和竞争目标。**

### 10.3 万国觉醒如何制造资源消耗

传统 SLG 的持续消耗不主要依赖清仓，而是依赖战争本身。

在 KVK 中，玩家会因为大规模战争产生：

- 兵员损耗；
- 医院治疗压力；
- 资源消耗；
- 治疗加速消耗；
- 迁城、增益、集结、驻防等战争道具消耗；
- 联盟为了争夺关卡、圣地、中央建筑而持续投入兵力和资源。

这形成了一个强资源黑洞：

```text
打架 → 伤兵 / 死兵 → 治疗 / 补兵 → 消耗资源 → 再打
```

因此《万国觉醒》不一定需要每赛季清空仓库，因为战争会持续吸收资源。

### 10.4 对本方案的借鉴与规避

本方案可以借鉴传统 SLG 的“临时赛季战场”和“联盟目标竞争”，但不应照搬其高压掠夺和重战损。

| 万国觉醒机制 | 本方案可借鉴为 |
|---|---|
| 失落之地临时地图 | 赛季战区 / 前线战场 |
| 王国 / 联盟目标 | 联盟前线建设 / 战区推进 |
| 赛季建筑争夺 | 战区据点 / 红区目标争夺 |
| 战争资源消耗 | 装备耐久、弹药、补给、角色状态、订单消耗 |
| 赛季排名 | 联盟战报、个人战报、服务器战役史 |
| 大佬带队 | 高危战区核心玩家承担突破任务 |
| 普通玩家参与 | 订单、后勤、资源提交、PVE 撤离贡献 |

同时需要规避：

| 万国觉醒机制 | 本方案不建议照搬 |
|---|---|
| 大地图长期掠夺 | 不打爆玩家基地 |
| 高强度死兵 | 不让角色 / 核心装备永久重损 |
| 强联盟压制普通玩家 | 战区分层、PVP 可选、基础成长不可封锁 |
| 24 小时战争压力 | 单局制、主动参与 |
| 强联盟垄断资源 | 基础资源保底，高级资源分层竞争 |

### 10.5 对撤离养成模式的启发

《万国觉醒》的核心思路可以总结为：

> 保留长期成长，重置临时战场，用战争消耗资源，用联盟目标制造竞争，用赛季结算沉淀荣誉。

本方案应将其改造成更适合二次元搜打撤的版本：

> 保留角色和基地，重置赛季战区，用撤离行动、兵工生产、前线建设和赛季订单消耗资源，用个人 / 联盟战报沉淀荣誉。

因此，在处理赛季切换和资源膨胀时，本方案不应简单清空玩家物资，也不应让玩家基地被攻击受损，而是通过临时赛季战区、新环境规则、新赛季资源、新联盟前线目标和战报结算，形成可持续循环。

## 11. 联盟概念设计

联盟不应该弱化，而是应该从传统 SLG 的“掠夺型联盟”转变为“战役型联盟”。

传统 SLG 联盟是：

```text
抢地 → 打人 → 占矿 → 做王
```

本模式更适合：

```text
协作 → 建设 → 远征 → 贡献 → 排名 → 纪念
```

### 11.1 联盟承担的作用

| 作用 | 说明 |
|---|---|
| 协作 | 共享情报、支援角色、提交资源、建设前线 |
| 目标 | 提供联盟订单、战区推进、Boss 击破等长期目标 |
| 竞争 | 前线贡献、红区积分、军工产值、探索进度排名 |
| 荣誉 | 赛季称号、联盟徽章、纪念碑、联盟战报 |

### 11.2 推荐联盟主循环

```text
个人进局搜物资
  ↓
资源用于个人基地 / 兵工厂
  ↓
多余或指定资源提交联盟订单
  ↓
联盟推进前线建设
  ↓
解锁联盟战区 / Boss / 商店
  ↓
联盟获得赛季积分
  ↓
赛季末结算联盟排名与个人贡献
  ↓
生成个人战报、联盟战报、服务器战役史
```

---

## 12. 赛季荣誉与分享欲

赛季最终不一定要靠打爆别人来产生荣誉，可以通过战区推进、前线建设、军工订单、Boss 击破、红区积分、联盟贡献、个人战报、服务器战役史形成终局仪式感。

### 12.1 四层荣誉结构

1. **个人荣誉**
   - 成功撤离次数；
   - 最高风险战区；
   - 带回最高价值物资；
   - 制造过的最强武器；
   - 完成订单数量；
   - 联盟贡献比例；
   - 赛季称号。

2. **小队 / 角色荣誉**
   - 本赛季 MVP 角色；
   - 出战最多角色；
   - 救援最多角色；
   - 搜索效率最高角色；
   - 最高羁绊小队；
   - 赛季合影。

3. **联盟荣誉**
   - 联盟总撤离次数；
   - 联盟军工产值；
   - 前线建设等级；
   - Boss 击杀次数；
   - 联盟排名；
   - 联盟称号。

4. **服务器 / 战区荣誉**
   - 本服战区推进进度；
   - 哪个联盟贡献最大；
   - 哪些玩家进入名人堂；
   - 哪个 Boss 被首杀；
   - 下赛季世界状态如何变化。

### 12.2 个人战报卡

赛季结束时可以生成个人分享卡：

```text
S1 边境军工战役 · 个人战报

玩家：XXX
联盟：第七前线
最高战区：红区 III
成功撤离：126 次
最高带出价值：58000
最常用角色：莉娅
最强制造武器：试作型电磁步枪
联盟贡献：前线建设 3.2%
赛季称号：红区回收专家
```

### 12.3 联盟战报卡

联盟也可以生成战报卡：

```text
S1 战区结算 · 联盟战报

联盟：第七前线
服务器排名：第 4
前线建设等级：Lv.8
累计撤离次数：8421
军工订单完成：328 单
Boss 击杀：12 次
最高贡献成员：XXX / XXX / XXX
联盟称号：精锐作战团
```

### 12.4 赛季冠军联盟

第 1 名联盟可以被包装为“战区总指挥部”，获得：

- 赛季冠军称号；
- 联盟徽章特效；
- 联盟基地纪念雕像；
- 成员头像框；
- 专属战区旗帜；
- 下赛季开场剧情提及；
- 服务器战役史永久留名。

奖励应以荣誉、外观、纪念为主，不应给过强数值优势，避免加剧滚雪球。

## 13. 商业化与大佬问题

资源争夺和氪金大佬一定会出现，但可以通过分层战区和战力压缩控制。

### 13.1 大佬可以更快，但不能让普通玩家没法玩

推荐原则：

- 基础成长不可被掠夺；
- 高级收益可以竞争；
- 大佬优势要有维护成本；
- PVP 不能覆盖所有成长路径；
- 赛季重置经济，不重置情感资产。

### 13.2 付费方向建议

适合付费：

- 角色抽取；
- 皮肤；
- 家具 / 基地外观；
- 生产队列扩展；
- 便利性月卡；
- 战术通行证；
- 外观枪皮；
- 宿舍互动内容。

谨慎付费：

- 高级武器；
- 高级蓝图；
- 稀有战区门票；
- 强属性装备；
- 资源直接购买；
- 建筑秒升。

不建议付费：

- 直接买顶级战力；
- 直接买赛季核心蓝图；
- PVP 数值压制道具；
- 无限死亡保护。

## 14. 阶段性结论

二次元搜打撤 + SLG 是一个可行方向，但必须避免两个极端：

1. 不能完全照搬硬核搜打撤，否则二次元用户会被高损失劝退；
2. 不能完全照搬传统 SLG，否则会变成大佬抢矿、普通玩家被压迫的模式。

推荐最终方向是：

> **轻量搜打撤 + SLG 基建 + 兵工厂制造 + 小队养成 + 联盟前线 + 软赛季重置。**

核心体验是：

- 普通玩家有稳定成长；
- 中度玩家有资源规划；
- 核心玩家有高危挑战；
- 大佬有追求和炫耀空间；
- 联盟有共同目标和赛季荣誉；
- 每个赛季都能留下个人和组织纪念。

最终一句话总结：

> 我们不直接照搬传统搜打撤，是因为“死亡全掉”难以适配二次元用户的角色养成与长期资产诉求，且单纯撤离循环后期容易物资膨胀、目标衰减；因此本方案将搜打撤改造为“撤离养成”：用局内风险获取资源，用局外基地、兵工厂、角色和联盟赛季持续消耗与沉淀资源，驱动玩家长期参与。
