# CLI 作为 Agent 工具接口

## 定义

指 Agent 不向模型枚举大量专用 MCP 工具，而是主要暴露一个（或少数）**命令执行入口**（如 `bash`），由模型生成 CLI 命令，调用系统中已有的命令行程序（`gh`、`ffmpeg`、`grep`、ImageMagick 等）完成任务。

## 要点

### Token：说明书极薄

相对 [[MCP]] 把数十个工具 schema 塞进上下文，CLI 路径通常只需一份简短的「执行命令」工具说明；具体能力来自模型对常见 CLI 的预训练知识，或来自 [[Agent Skill]] 对冷门工具的文档补充。

### 效率：组合代替多轮调度

UNIX 哲学——**每个工具做好一件事，用 `|` / `&&` 组合**——让「筛图 → 加水印 → 上传」可在一次 shell 调用内本地跑完，中间结果不必每步回模型。链路短、墙钟时间往往更优。

### 代价：可控性与安全

- 复杂命令易因引号、空格、特殊字符出错，且错误隐蔽
- 任意命令面过大（如误用 `rm -rf`）；本地可自负，共享云端通常需沙箱，成本高、仍难达到 MCP 级能力边界

## 适用场景（来自 [[mcp-vs-cli]]）

个人开发、本地 Agent、追求速度与成本的轻量场景。行业信号：部分团队公开转向 API/CLI，减少 MCP 依赖。
