## 与本知识库的关联

本库收录其视频文稿《为什么越来越多的人抛弃 MCP，转向 CLI？》，讨论 Agent 场景下 [[MCP]] 与 [[CLI作为Agent工具接口]] 的取舍，并触及 [[Agent Skill]] 作为冷门 CLI 说明书的角色。

## 核心观点（来自 [[mcp-vs-cli]]）

- CLI 因 Token 更省、链路更短，在个人与轻量 Agent 中会更常见
- MCP 在可控性与安全性上更强，适合企业与云端
- 最终格局：CLI 走向个人，MCP 留在企业和云端
