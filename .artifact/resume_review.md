# 个人简历优化梳理

## 总体判断

这份简历的核心优势很明显：游戏开发经验长、经历过多个引擎、既做过项目架构也做过 UE 开放世界 PCG 工具链，并且有技术奖、专利和项目落地成果。当前主要问题是表达偏口语化，部分段落过长，项目成果和职责混在一起，导致“游戏引擎/渲染工程师”的定位不够集中。

## 建议优先优化点

1. 简历标题建议明确方向：`游戏引擎 / 渲染 / PCG 工具链 高级开发工程师`。
2. 自我介绍建议压缩成 3-4 条，突出：多年经验、UE/PCG、架构能力、获奖/专利。
3. 腾讯经历建议拆成 3 个项目：`华夏 MMORPG / 英雄无敌 SLG / 欢乐麻将`，不要堆在一个大段里。
4. 网易经历建议突出“从 0 到 1 架构 + 支撑 150+ 子游戏”，这是非常强的量化成果。
5. 主要成果部分可以保留 3-4 个代表项，删除或压缩过长解释，避免简历像技术文档。
6. 专利列表可精简为“拥有 9 项游戏/图形/交互相关专利，其中包括……”，不必全部展开。
